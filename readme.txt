■概要
このゲームはスイカゲームを模して作ったゲームです。

■使用ソフト/言語
ソフト：Untiy2023.2.201f
言語：C#

■工夫した点
・複数の管理オブジェクトを作成し、プレイヤーオブジェクトやUIなどの各要素の処理とゲーム全体の状態管理を整理しました。
　これにより状態遷移の制御や共通処理の管理が容易になり、エラー耐性・安定性・可読性を意識した設計としました。

・管理オブジェクトをシングルトンオブジェクトとして運用することで、ゲーム全体の管理を一貫して行える構成とした。

・変数や値の管理方法を工夫し、オブジェクト間の参照を簡略化するとともに、エラーの未然防止を実現した
　例）列挙型による指定ミスの防止、静的変数の活用による共通データの管理
　　　バリデーションチェックによる堅牢な防止策の実装

・jsonファイルによる記録可能なデータの管理

・プレイヤーをコントローラーとオブジェクトの２クラス制御による処理の簡易化

■苦労した点
・管理オブジェクトによる各要素やオブジェクトの状態管理
・処理の流れの把握と制御
・動的変数の参照の動きの制御
・オブジェクト間の参照の受け渡し
・AudioMixerとUIの連携

■今後の改善点
・エフェクト実装による見栄えの向上
・動的UIの実装による見栄えの向上
